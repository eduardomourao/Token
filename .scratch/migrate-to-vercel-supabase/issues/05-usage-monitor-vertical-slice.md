# 05 — Primeiro fluxo vertical: monitor de uso

**What to build:** um monitor autenticado de leitura que usa dados Supabase, atualiza após coleta programada e preserva os contratos visuais/interativos relevantes do monitor atual.

**Blocked by:** 02 — Fundação Supabase de desenvolvimento; 03 — Fundação de preview Vercel; 04 — Harness de paridade de contratos.

**Status:** ready-for-agent

- [ ] O monitor mostra dados autorizados, estados de carregamento, indisponibilidade e última atualização.
- [ ] A coleta é idempotente e a atualização visual ocorre depois da persistência.
- [ ] A paridade funcional é comprovada antes de qualquer promoção.
