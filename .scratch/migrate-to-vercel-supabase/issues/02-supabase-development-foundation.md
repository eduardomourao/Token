# 02 — Fundação Supabase de desenvolvimento

**What to build:** estrutura versionável para desenvolvimento Supabase, incluindo configuração local, migração inicial vazia/segura, convenções de RLS e documentação de segredos, sem criar projeto remoto nem importar dados reais.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] A estrutura é segura para versionamento e não contém URLs, chaves ou dados reais.
- [ ] O primeiro esquema declara ownership, RLS e a separação entre acesso do navegador e operações de serviço.
- [ ] Há uma forma reversível e testável de aplicar a fundação em ambiente de desenvolvimento.
