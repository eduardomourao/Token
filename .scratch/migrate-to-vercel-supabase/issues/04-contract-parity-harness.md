# 04 — Harness de paridade de contratos

**What to build:** uma matriz executável para comparar o runtime atual e o primeiro fluxo migrado, cobrindo autenticação, leitura de monitoramento, atualização automática e falhas previsíveis.

**Blocked by:** 02 — Fundação Supabase de desenvolvimento; 03 — Fundação de preview Vercel.

**Status:** ready-for-agent

- [ ] A matriz define dados de entrada, resultado esperado e tolerância de atualização por fluxo.
- [ ] Divergência relevante bloqueia promoção e aponta o rollback aplicável.
- [ ] Os testes não exigem conta real, segredo real ou produção.
